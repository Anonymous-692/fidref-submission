SKILL APPLICABILITY CONTRACT SYNTHESIS — REVIEW ARTIFACT

This artifact contains experiment code, configurations, preserved runs, and analysis
inputs. The paper is submitted separately.

QUICK START
  python3 restore_results.py
  python3 verify_latest.py

Run both commands from the extracted release root. restore_results.py validates every
results.tar.xz member before extraction and refuses unsafe paths or unexpected
overwrites. verify_latest.py uses only the Python standard library. It verifies release
file hashes, the explicit 58- and 52-run replacement maps, and recomputes stored Exact,
IoU, CFR, McNemar, and Holm values from final evaluation coefficients. It also checks
the partial-pool, hosted-API, and Calendar-14B raw artifacts against frozen audits.
Hosted-API cohorts are recomputed for n, Exact, parse failure, valid-evaluation count,
state/success counts, outcome distribution, and mean IoU/CFR.

The commands above perform no network, API, model, GPU, or fresh closure-evaluation
calls. They verify preserved results; they do not rerun model generation.

FULL CODE ENVIRONMENT
  python3.13 -m venv .venv
  .venv/bin/python -m pip install -r requirements.txt
  .venv/bin/python -m unittest discover -s experiment/tests -t .
  .venv/bin/python reproduce.py verify
  .venv/bin/python reproduce.py stats
  .venv/bin/python reproduce.py figures

The exact test count can change with the packaged code; rely on the command's exit
status rather than an older count. reproduce.py all runs baseline verification and
statistics and recomputes convergence outputs under outputs/. CPU closure rescoring can
take several minutes. These commands use preserved artifacts and make no model API calls.

DATA AND CONDITIONS
  analysis/cell_manifest_2026-09-04.json identifies original cells and seeds.
  Additional model, reasoning, retry-policy, and adaptive-budget checks are under
  analysis/. Original and retry attempts are linked by explicit manifests; do not pool
  both attempts as independent seeds. Earlier partitioned retail Sampled runs and the
  later fixed-pool arm retain distinct identifiers and protocol scope. Failure outcomes
  remain in their recorded denominators. Missing cost is not treated as zero cost.

PROVENANCE AND ANONYMIZATION
  Infrastructure endpoints and personal local paths have been redacted. Supplied
  endpoints are localhost examples for new executions. Model identity, software and
  hardware metadata, decoding, budgets, contracts, evaluations, and recorded protocol
  hashes are preserved. RELEASE_MANIFEST.json hashes files in this release. Historical
  source/protocol hashes describe pre-anonymization artifacts and remain separate from
  release_sha256. Release verification is not fresh model or closure replay.

NEW MODEL EXPERIMENTS
  Start a compatible model server, then inspect a domain runner:
    .venv/bin/python -m experiment.deployment.model_runner --help
    .venv/bin/python -m experiment.calendar.model_runner --help
    .venv/bin/python -m experiment.shopping_price.model_runner --help
    .venv/bin/python -m experiment.taubench_retail.model_runner --help
  Configure model identity and base_url for your server. Preserve budget, prompt,
  structured-output, and reasoning settings for a comparable cell. Serving dependencies
  are installed separately for the chosen hardware. These commands may contact your
  configured server; they are not part of preserved-result verification.
